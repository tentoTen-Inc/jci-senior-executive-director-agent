# リッチメニューと LIFF の役割ごとの構成 詳細設計 v1.0

最終更新: 2026-10-25（専務承認:「この構成で進めて」）
前提: `docs/doc-session-design.md`（チャットは検索のみ・資料の作業セッション。§3 のメニュー構成はこの設計に置き換え）、
日程調整 `docs/schedule-poll-design.md`（LIFF アプリ・IDトークンでの本人確認を流用）、LINE 連携 `docs/line-link-design.md`

## 1. 基本の考え方
| 場所 | 役割 |
|---|---|
| リッチメニュー | よく使う入口だけ |
| LIFF | 一覧・選択・入力（表や複数の項目を扱う画面） |
| トーク | AI への質問（検索のみ）と、資料の作業セッション |

書き込みは、ボタンか LIFF の［送信］を押したときだけ（chat-read-only の原則）。

## 2. リッチメニュー
| ボタン | 会員 | 理事（委員長・直前理事長） | 五役（理事長・副理事長・専務理事・監事）・事務局 |
|---|:-:|:-:|:-:|
| 予定と出欠（LIFF） | ○ | ○ | ○ |
| 日程調整（LIFF） | ○ | ○ | ○ |
| AIに聞く（質問の例を返す） | ○ | ○ | ○ |
| 意見箱（LIFF。旧「事務局に連絡」） | ○ | ○ | ○ |
| 資料を作る・直す（作業セッション） |  | ○ | ○ |
| 委員会の議案（LIFF） |  | ○（自分の委員会） | ○（全委員会） |

- 会員用は 2×2、理事用は 3×2。
- 五役用はタブ切り替え（rich menu alias ＋ richmenuswitch）で2枚。上部にタブ「みんな｜運営」を置く。
  - 1枚目「みんな」: 上の6つ
  - 2枚目「運営」: 予定を登録・変更／出欠の状況（LIFF）／日程調整を作る（LIFF）／承認待ち（LIFF）／管理画面を開く（https://admin.647jc.org）
- 立場の判定: 五役用＝予定の操作ができる人（理事長・副理事長・専務理事・監事・事務局）。理事用＝それ以外の理事メンバー（委員長・直前理事長）。直前理事長は理事用（予定の操作の権限は持たせない）。
- メニューの ID とタブのエイリアスは `Settings.rich_menus`（member / board / officer / officer_ops）に保存し、
  LINE 連携の承認・招待コード・組織図の取込のときに会員ごとに結びつける。
- LIFF のボタンは、LIFF ID があれば `https://liff.line.me/{LIFF_ID}?view=…` を直接開く（uri アクション）。
  無い間は postback でトークに一覧を返す（§4）。
- 旧メニューのボタン（`menu|出欠を回答`・`menu|次回の予定`・`menu|自分の出欠状況`・`menu|使い方`）が届いても動くよう残す。

## 3. LIFF 画面
| 画面（`?view=`） | 使う人 | できること |
|---|---|---|
| 予定と出欠（`events`） | 全員 | これからの予定一覧・その場で出欠を回答・変更・自分の回答状況 |
| 日程調整（`polls`） | 全員 | 回答待ちの日程調整の一覧 → 既存の回答画面（`?poll=`）へ |
| 委員会の議案（`proposals`） | 理事・五役 | 議案の状態・締切・議案書リンク・審議の記録。［この資料で作業する］で作業セッション開始 |
| 出欠の状況（`attendance`） | 五役・事務局 | 予定ごとの出欠・未回答者。［未回答者に催促］は確認のうえ送信 |
| 日程調整を作る（`poll-new`） | 五役・事務局 | 候補日と送り先を選んで作成（管理画面と同じ処理） |
| 承認待ち（`approvals`） | 五役・事務局 | LINE 連携の申請（承認・却下）・専務確認待ちの議案 |
| 意見箱（`feedback`） | 全員 | 種類・内容・匿名を選んで［送る］（`docs/feedback-box-design.md`） |

- 既存の LIFF アプリ（`/liff/poll`）に `?view=` の切り替えを足す（LINE Developers の設定変更は不要）。画面の処理は `/liff/views.js` に分ける。
- API は `/liff/api/…`。LINE の IDトークンで本人を確かめ、**役割に応じたアクセス制御をサーバー側で必ず行う**（画面の出し分けに頼らない）。
- ［この資料で作業する］は、サーバー側で作業セッションを始め、ボットから「📝 編集中…」を送る（`liff.sendMessages` の自由文に頼らない）。
- 書き込み（出欠の回答・催促・日程調整の作成・連携の承認）は［送信］系のボタンを押したときだけ。
- 実装の決めごと（L2）:
  - ［未回答者に催促］は定期の催促と同じ出欠依頼を個別トークへ送る（配信のガードレール・配信記録を通す）。夜間（静音時間）は送らず、同じ予定へは1時間に1回まで。
  - 日程調整は［作成する］では送らず、送り先のグループ名を出したうえで［グループに案内する］を押したときだけ案内する。案内先は対象者（五役／理事／会員全員）から管理画面と同じ名前のグループを選ぶ。
  - LINE 連携の承認・却下は、LINE のボタンと同じく専務理事のみ（他の五役・事務局は一覧を見るだけ）。専務確認待ちの議案は一覧のみで、確認結果は管理画面から登録する。
  - 事務局は委員会の議案を見られるが、資料の作業（［この資料で作業する］）は理事メンバーのみ。

## 4. LIFF ができるまでのトークでの代わり
| ボタン | トークでの動き |
|---|---|
| 予定と出欠 | 次回の予定＋出欠の案内（出席・欠席のボタン） |
| 日程調整 | 回答待ちの日程調整の一覧（回答画面へのリンク） |
| 委員会の議案 | 議案の一覧（状態・締切・議案書リンク） |
| 出欠の状況 | 直近の予定の出欠の集計と未回答者 |
| 日程調整を作る・管理画面を開く | 管理画面へのリンク |
| 承認待ち | LINE 連携の申請と専務確認待ちの議案の一覧 |
| 意見箱（旧「事務局に連絡」のボタン・短い文「連絡」も） | 意見箱の案内（LIFF を開くボタン）と「急ぎの用件は専務に直接 LINE」。書き込みなし |
