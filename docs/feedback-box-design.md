# 意見箱 詳細設計 v1.0

最終更新: 2026-10-25（専務の依頼:「事務局に連絡は不要。専務理事が誰か全員知っているので直接LINEできる。
代わりに、バグ報告や欲しい機能の要望など多様な意見を抽出できる意見箱的な機能がほしい。」）
前提: `docs/liff-menu-design.md`（メニューと LIFF）、`docs/doc-session-design.md` §1（チャットは検索のみ）

## 1. 目的
専務AI への不具合の報告・ほしい機能・使いにくい点などを、会員から気軽に集めて整理する。
急ぎの用件は専務に直接 LINE してもらう（ボットは取り次がない）。

## 2. メニュー
- 全メニュー（会員用・理事用・五役「みんな」）の［事務局に連絡］を［意見箱］に置き換える。LIFF（`?view=feedback`）を直接開く。
- 旧ボタン（`menu|事務局に連絡`）・短い文「連絡」「事務局」等が届いたら、意見箱の案内（LIFF を開くボタン）と
  「急ぎの用件は、専務に直接 LINE してください」を返すだけ。**書き込みはしない**（連絡票 `Escalation` も作らない）。
- 書き込みはボタン・LIFF の［送る］からだけ（チャットは検索のみの原則を維持）。

## 3. 送り方
| 入口 | 種類 | 保存 |
|---|---|---|
| LIFF「意見箱」 | 不具合／ほしい機能／使いにくい点／その他（必須）・内容（必須・2000字まで）・匿名で送る | ［送る］→ 確認 → 保存 →「ありがとうございました」 |
| AI が答えられなかった質問の［意見箱に送る］ | AIが答えられなかった（`unanswered`） | 押したときだけ、その質問を名前つきで保存（同じ質問の二重押しは1件） |

- 匿名なら会員ID を保存しない（LINE の userId・名前も残さない）。管理画面・通知にも「匿名」と出す。
- 本人確認は LINE の IDトークン（LINE 連携済み・在籍の会員のみ）。
- 以前の［事務局に取り次ぐ］のボタン（`esc|…`）が押されても、意見箱への保存として扱う。
- AI への質問の指示（`_QA_PROMPT`）から「事務局へ案内する」を外し、人の判断が要る依頼は「専務理事に直接 LINE で相談」と案内する。

## 4. AI の分類と通知（tick で非同期）
- 保存: Firestore `feedbackBox/{feedback_id}`（`Feedback`）。傾向のまとめは `settings/feedbackDigest`。
- tick ごとに、分類していない意見を最大5件、AI（`feedback_triage`・Pro）で分類する:
  種類の補正（送った人の選択は `kind` に残し、補正は `triage.kind`）・対象の機能・緊急度（高/中/低）・一行要約。
  失敗したら1時間後に再試行する。
- 通知: まだ知らせていない意見を、専務理事に LINE で短く知らせる（複数ならまとめて1通）。
  不具合を含むときは先頭に【不具合】。静音時間（既定 21:00〜08:00）は送らず、明けた tick で送る。
  送信は既存の配信（ガードレール・配信記録）を通す。分類に失敗しても、選んだ種類で知らせる。

## 5. 管理画面「意見箱」（/app/feedback）
- 一覧: 種類（AI の補正後。補正したときは送った人の選択も表示）・緊急度・対象の機能・状態・要約・本文・日時・送った人 or 匿名。
- 状態: 新規／対応中／完了／見送り（プルダウンで変更。監査ログ `feedback.status`）。絞り込み: 未完了・状態別・すべて。
- 傾向のまとめ: ［AI でまとめる］で、見送りを除く新しい順 200 件までを AI（`feedback_digest`・Pro）が論点にまとめる。
  件数は AI に数えさせず、論点ごとの意見の id から数える。論点を押すとその意見だけを表示する。
- 左メニューに「意見箱」（新規の件数）。
