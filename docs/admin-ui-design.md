# 管理画面 UI 刷新（C案「LINE なじみ」）設計 v1.0

最終更新: 2026-10-21
前提: 管理画面 `docs/dashboard-design.md`。専務の選択は **C案（LINE なじみ）**、**PC で主に使い、スマホでも崩れない**こと。

## 1. 目的
- 開いた瞬間に「今日やること」が分かり、その場で片付けられる（件数を押すと対応画面へ）。
- 専務以外（事務局・理事長）が触っても説明が少なくて済む（LINE と同じ見た目・言葉）。
- 開発用の言葉を画面から消す。

## 2. デザインの決まり（トークンは `web/tailwind.config.js`・部品は `web/src/components/ui.tsx`）
| 項目 | 決まり |
|---|---|
| 色 | 背景 `#F7F7F8`、カード `#FFFFFF`、文字 `#111111`／補足 `#6B7280`、**主色 LINE 緑 `#06C755`**（押せる・進捗・完了）、注意 `#D92D20`、保留 `#B54708`、情報 `#175CD3` |
| 書体 | M PLUS 1p（見出し 800、本文 400/500）。数字は等幅数字（`tabular-nums`） |
| 形 | カード角丸 18px、ボタン・タグは丸（pill）、入力欄 12px。影は使わず、背景との差で区切る |
| ボタン | 主（緑・白文字）は1画面に1つまで。副（灰）、文字だけ（ghost）、危険（赤文字） |
| 表 | `.tbl`（見出し灰小さめ、行は罫線のみ）。PC は表、スマホは横スクロール |
| 確認 | ブラウザ標準の confirm は使わず `useConfirm()`（送信・削除は送り先や件数を明記） |
| 通知 | 操作の結果は `useToast()`（右下に数秒） |
| 空のとき | `EmptyState`（何が無いか＋次にやること）。設定の手順説明は設定画面へ |

## 3. 画面構成（メニュー）
| メニュー | パス | 中身 |
|---|---|---|
| ホーム | `/` | 今日やること（要対応・日程調整・今後2週間・LINE 連携） |
| 予定・出欠 | `/events` | 予定の一覧（月ごと）・登録・出欠・カレンダー連携 |
| 日程調整 | `/polls` | 候補日の調整・回答の表・案内/催促/決定 |
| 会員・LINE 連携 | `/members` | 名簿・LINE 連携の承認・招待コード |
| 議案 | `/proposals` | 議案の進み具合 |
| 連絡・アンケート | `/notices`, `/surveys` | 対外連絡・アンケート（上部の切替で行き来） |
| 記録: LINE のやり取り | `/line-groups` | グループの会話とファイル |
| 記録: AI の回答 | `/ai-answers` | AI の回答の振り返り |
| 記録: 送信の記録 | `/agent` | 送信と操作の記録 |
| 設定 | `/settings` | 年度・送信の一時停止・静音時間・催促のタイミング |

メニューには対応が必要な件数を出す（ホーム＝要対応の合計、日程調整＝受付中の数、会員＝連携の承認待ち）。
幅 1024px 未満では左メニューを上部の「メニュー」ボタンで開く引き出しにする。

## 4. 言葉の置き換え（画面に出さない言葉）
| 使わない | 代わりに |
|---|---|
| キルスイッチ | 送信の一時停止 |
| dry-run／取込確認 | 取り込む前に確認 |
| seed／既定ポリシー投入 | 標準の設定に戻す |
| tick | 毎時の自動処理 |
| rp_例会_default 等のID、会員ID（m14）、LINE の内部ID、poll_… | 名前・タイトル |
| unknown（操作者） | 自動処理 |
| 距離 0.28 | 関連度（高・中・低） |
| サービスアカウントのメールアドレス | 設定画面の「連携の準備」にだけ書く |

## 5. 実装フェーズ
1. 部品・メニュー・ホーム（本 PR の最初のコミット）
2. 予定・出欠／日程調整／会員
3. 議案・連絡・アンケート・記録・設定
4. スマホ幅の確認と仕上げ
